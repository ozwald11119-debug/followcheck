# FOLLOW CHECK v3 / PWA版

Instagramからユーザー自身がダウンロードしたフォロワー・フォロー中データをブラウザ内だけで比較する静的Webアプリです。

## 主な機能
- フォロバされていない人
- 相互フォロー
- 相手だけがフォローしている人
- フォロー中 / フォロワー全件
- 前回との差分
  - 新規フォロワー
  - フォロー解除された人
  - 新しく相互になった人
- 検索
- CSV保存
- 端末内履歴保存
- PWA対応（ホーム画面追加）
- アプリアイコン
- 初回向け図解ガイド

## 公開
このフォルダ一式を HTTPS で配信してください。
GitHub Pages / Cloudflare Pages / Netlify / Vercel などの静的ホスティングで公開できます。

PWA / Service Worker は file:// 直開きでは完全には動きません。HTTPS公開後に有効になります。

## プライバシー
- InstagramのID・パスワードは取得しません
- 読み込んだフォロー関係はブラウザ内で処理します
- 比較履歴はlocalStorageへ保存します

## 注意
ZIP解析はJSZipをCDNから読み込みます。
Instagram / Metaのデータ書き出し形式が変わった場合はパーサー調整が必要です。
